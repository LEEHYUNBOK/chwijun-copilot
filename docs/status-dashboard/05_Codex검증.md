## 감사 범위 (Codex에게 준 6개 항목)

1. 집계 정확성 — 판정표 ↔ 채점자 원본, 채움률·일치율·편차 재계산
2. 판정 타당성 — 기준 문구 대비 수기·채점자 판정, 03 해석의 타당성 (위키 원본 직접 확인)
3. 회귀 설계·분석 — 픽스처 변형이 설명대로인가, doc_A 실패 원인 분석
4. 결론 과장 여부 — 통과 판정이 사전 고정 조건과 맞는가
5. v1 개정 후보 — 근거 일치, 누락 결함, 개정안의 부작용
6. 마스킹 — 동료 실명·식별자 잔존

## Codex 총평 (원문 요약)

> v0의 실제 약점은 회귀 실패가 보여준 C5의 분류 경계와 블라인드가 확인한 C3·C7의 해석 여지에 있다. 기준선 보정 조건이 모호해 통과를 독립적으로 재현하기 어렵다. v1 개정 후 재테스트하는 방향은 타당하다 — 단 새 문서 표본을 추가하고, 보정 규칙과 픽스처 변형 범위를 사전에 구체화해야 한다.
