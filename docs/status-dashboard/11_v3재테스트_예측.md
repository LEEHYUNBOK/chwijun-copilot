# v3 재테스트 — 설계와 사전 예측 (실행 전 고정, 결과는 `11_v3재테스트.md`)

> 2026-11-15. 이 파일은 채점자 실행 직전에 SHA-256을 `사전예측_해시_v3.txt`에 기록하고 이후 고치지 않는다(09와 같은 방식).

## 목적

1. v3 #1~#3이 v2 재테스트의 불일치 칸(e1 C3·C4, e2 C3, e3 C2, e4 C2)을 해소하는가
2. 기준을 좁힌 뒤에도 기존 일치 칸(d3·d4 14칸 등)이 유지되는가
3. 보류 항목(#3 장애 문서 C4, #5 벤치마크 C4)의 재료를 모은다 — 장애 문서 f1, 벤치마크 문서 f2 추가
4. 누적 채점 위키 문서를 10개로 만들어 가중치 재검토(v1 #7)의 재료로 쓴다

## 설계

| 항목 | 내용 |
|---|---|
| 기준 | `01_채점기준_v3.md` |
| 채점자 | W-1, W-2, W-3 — 서브에이전트 3명, 격리 폴더, 동일 지시문(09와 같은 문안, 파일 목록만 추가) |
| 문서 | 09와 같은 6개(d3·d4·e1·e2·e3·e4, 바이트 동일 확인) + **f1 LLM-키등록-폐기교착(장애), f2 성능-부하테스트(벤치마크)** |
| 집계 | `python3 집계.py` (09와 같은 스크립트) |
| 식별자 검사 | 출력 전체에서 사람 이름·티켓 번호·테이블명·지원 회사명·코드 클래스명 grep + 영문 토큰 목록 확인 |
