### 두 기준선에서의 판정 (Codex 감사 상-2 대응)

Codex 감사가 "사전 규칙의 '차이가 크면'에 수치 기준이 없어, 결과를 본 뒤 기준선을 고른 모양새"라고 지적했다. 맞는 지적이다 — 규칙이 모호했다. 그래서 **보정 전·후 기준선 둘 다로** 판정해 결론이 기준선 선택에 좌우되는지 확인한다.

| 픽스처 | 통과 조건 | 수기 기준선으로 | 보정 기준선으로 | 판정 변화 |
|---|---|---|---|---|
| doc_A | C5 비어 있음 + 채움률 하락 | C5 부족 ✗ / 78.6% > 71.4% ✗ → **실패** | C5 부족 ✗ / 78.6% = 78.6% ✗ → **실패** | 없음 |
| doc_B | C4·C5 한계 명시 | 둘 다 한계 명시 → **통과** | 같음 → **통과** | 없음 |
| doc_C | C4·C5 충분함 | 둘 다 충분 → **통과** | 같음 → **통과** | 없음 |
| doc_D | 5/7 이상 일치 + ±15%p | 5/7, 14%p → **통과**(경계선) | 7/7, 0%p → **통과** | 없음 |

**어느 기준선을 써도 판정은 같다.** 보정은 결론을 바꾸지 않고 해석(doc_D가 경계선 통과인지 완전 일치인지)만 바꾼다. 다음 재테스트부터는 규칙을 수치로 고정한다: *"블라인드 다수결과 수기 채점의 판정이 다른 칸이 **해당 블라인드 테스트의 전체 판정 칸 합계 기준**(문서 수 × 7칸)으로 3칸 이상이면 다수결을 기준선으로 쓰고, 두 기준선의 판정을 모두 보고한다. 판정 4단계(충분·부족·비어 있음·한계 명시) 중 단계가 다르면 1칸으로 센다."* (Codex 재감사 중-3 반영 — 초판은 합산 단위가 없었다. 이번 블라인드는 NL2SQL 2칸 + 권한재설계 1칸 = 3칸으로 이 규칙에도 해당한다)

⚠️ 이 규칙은 **결과를 본 뒤에** 만든 것이다. 이번 테스트에 소급 적용한 것이 아니라 다음 테스트용이며, 이번 결론은 "두 기준선 판정이 같다"는 사실에만 기댄다.

   - **픽스처 설계도 원인이다**(Codex 감사 상-1 반영 — 초판은 이를 부수적 한계로만 적었다): 설계표는 doc_A를 "KPI 관련 서술 전부 삭제"라고 설명했지만, 「문제」·「실행」 절의 구조 수치(최대 6개 파일, JSP 6→1)는 남겼다. v0 기준이 명시적으로 제외한 것은 노력량뿐이므로, 채점자가 이 구조 수치를 C5의 "관련 내용"으로 받을 여지를 픽스처가 남겼다. **실패 원인 = 기준 결함(구조 수치를 KPI에서 제외하지 않음) × 픽스처 한계(그 구조 수치를 남김)의 결합**이다. 둘을 분리하는 재실험이 아래 doc_A2다

### 추가 발견

- **가상 수치에 92.9%가 나왔다 (doc_C).** 채점은 문서에 쓰인 수치를 그대로 믿는다. doc_C의 「결과」 절에는 근거 링크가 하나도 없는데 R-D는 이를 지적하지 않았다. 대시보드가 "지어내서 퍼센트를 올리는" 유인을 막으려면 **수치 칸(C4·C5)의 충분함 조건에 「근거」 절 링크를 요구**해야 한다 — 위키 규칙("근거를 `_보관/`에 먼저 만들고 위키를 쓴다")과도 맞는다
- **절 하나가 4칸을 동시에 움직였다 (doc_C).** 「결과」 절 추가로 C4·C5·C6·C7이 한꺼번에 올랐다. 칸들이 서로 독립적이지 않다 → 같은 1/7 가중치가 맞는지(v0 미결 사항)에 대한 실측 근거
- doc_D(원본과 바이트 동일)가 보정 기준선과 7/7 일치 → 같은 문서는 같은 판정이 나온다(일관성 확인)

### 재실험 결과 — doc_A2 (R-E, 원본 `채점자원본/R-E_회귀재실험_docA2.md`)

**판정: 예측 실패.** 채움률은 예측 범위에 들어왔지만 C5가 아니라 C1이 떨어진 결과라, 하향 감지에 성공한 게 아니다.

**해석 — 사전에 정한 해석 규칙대로 R-E의 근거 위치를 추적했다:**

1. **관찰: 구조 수치를 지워도 R-E는 정성 결과를 근거로 C5를 부족함으로 판정했다.** R-E는 "before→after 수치가 없다. 정성 결과(사이드바가 DB 주도로 전환됨)뿐"이라고 쓰고도 부족함을 줬다. 판단문에 기준의 "내용이 일부라도 있으면 부족함" 규칙이 그대로 드러난다
   → **원인 분리는 제한적이다**(Codex 재감사 상-1 반영 — 초판은 "주원인은 기준 규칙, 픽스처 한계는 부차적"이라고 확정했으나 근거보다 강했다). 이유 두 가지:
     - 채점자가 바뀌었다(doc_A는 R-C, doc_A2는 R-E). C5가 같게 나온 것이 기준 규칙 때문인지 채점자 차이와 섞인 것인지 이 설계로는 가를 수 없다
     - 교란이 실제로 생겼다(아래 2번 — C1 동반 하락)
   → 말할 수 있는 것: **"구조 수치가 없어도 정성 결과만으로 C5가 0.5를 받는 경로가 존재한다"는 것은 R-E 판단문으로 직접 확인됐다.** 그러므로 v1 #1의 개정 방향(정성 결과만 있으면 비어 있음)은 doc_A·A2 어느 쪽 원인이든 필요하다
   → 원인을 확정하려면: **같은 채점자가 doc_A와 doc_A2를 각각 채점**(또는 채점자 3명이 두 문서를 모두 채점해 다수결)하는 후속 설계가 필요하다 — README 체크리스트에 추가
2. **C1이 같이 떨어졌다 — 교란을 막으려던 설계가 실패했다.** 문제 서술은 남기고 숫자만 뺐지만, R-E는 "영향의 크기(얼마나)가 없다"며 C1을 부족함으로 내렸다. **"최대 6개 파일"은 C1의 영향 크기 근거였다.** 같은 숫자가 C1(문제의 크기)과 C5(결과의 before 값)에 동시에 쓰인다는 뜻이고, 회귀 doc_C에서 본 "칸들이 독립적이지 않다"(v1 #7)의 두 번째 사례다
3. 같은 기준·같은 원본 계열인데 R-C(doc_A)와 R-E(doc_A2)의 C2~C7 판정은 전부 같았다(달라진 것은 숫자를 뺀 C1뿐) — 채점자가 바뀌어도 칸 판정은 안정적이다

### 기록 메모
