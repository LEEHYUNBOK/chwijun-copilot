## 3. 채우기 흐름 1회

- 대상: 최저점 문서(클라우드 이관 산정, 7.1%)의 C1
- 진행: 질문 1개 → 사용자 답 → 「배경」 절 4줄 수정안 → 확인 후 반영 → 맥락 없는 채점자 1명이 재채점
- 결과: 7.1% → 50.0%

| 칸 | 전 → 후 | 원인 |
|---|---|---|
| C1 | 비어 있음 → 충분함 | 추가한 「배경」 절 (의도한 변화) |
| C3 | 비어 있음 → 부족함 | 배경의 "전수 조사로 진행" 문장이 부분 근거가 됨 |
| C2·C7 | 비어 있음 → 부족함 | 본문 변화 없음 |
| C4 | 비어 있음 → 충분함 | 본문 변화 없음 |

**관찰:** 재채점을 채점자 1명이 하면, 손대지 않은 칸도 흔들린다. 이번 상승분 중 C1 덕분인 것은 1점(14.3%p)이고, 나머지는 채점자 편차가 섞인 값이다. 13에서는 채점자 3명 다수결로 이 편차를 눌렀지만, 스킬의 기본 흐름은 1명이다. 다음 개선 후보로 둘이 있다.

- 재채점 때 이전 판정을 넘기지 않으면서도 "바뀐 절과 무관한 칸은 이전 판정 유지"를 기본값으로 둔다.
- 또는 재채점할 때만 채점자 3명 다수결을 쓴다.
