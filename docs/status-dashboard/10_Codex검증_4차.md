# Codex 4차 감사 — v2 재테스트(09)

> 2026-11-15. 감사 방식은 이전과 같다(`codex exec --skip-git-repo-check -s read-only --ephemeral`). 기준·예측·해시 파일·결과·집계.py·채점자 원문 3개를 읽혔고, 위키 원문 6개도 직접 읽게 했다. 채움률은 암산하지 말고 `집계.py`를 실행해 대조하라고 지시했다. 3차 감사에서 나온 산술 오류 3건에 대한 대응이다.
> 감사 원문: `채점자원본/Codex_4차감사원문.md` (수정 없이 보관)

## Codex가 이상 없음으로 확인한 것

- 판정표는 채점자 원문의 `판정:` 줄과 일치한다. Codex가 `집계.py`를 직접 실행해 얻은 출력도 기록(전원 일치 36/42, 다수결 42/42, 채움률·편차)과 같다.
- 예측 파일·기준 v2·집계.py의 SHA-256은 `사전예측_해시_v2.txt`와 일치한다.
- 채점자 원문과 결과 기록에 동료 실명·티켓 번호·테이블명·지원 회사명·코드 클래스명이 없다. 채점자 원문에 `%` 표기가 없다.
- v3 후보 #1(한계 명시는 해당 칸에만 적용)과 #3(장애 문서 C4 보류)은 원문에 근거한다.
- 다수결 판정이 기준상 명백히 틀린 칸은 없다.

**이번에는 산술 오류가 없었다.** LLM이 판정만 내고 스크립트가 계산하는 방식(v2 #7)으로 바꾼 뒤 처음 한 감사다.
