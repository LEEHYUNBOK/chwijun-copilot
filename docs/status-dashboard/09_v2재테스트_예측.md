# v2 재테스트 — 설계와 사전 예측 (실행 전 고정, 결과는 `09_v2재테스트.md`)

> 2026-11-15. 이 파일은 채점자 실행 직전에 SHA-256을 기록하고 이후 고치지 않는다(Codex 3차 감사 하-10 권고: 예측을 결과와 분리).

## 목적

1. v2 개정(#1~#5)이 v1 재테스트의 불일치 칸(d3 C3·C5, d4 C5)을 해소하는가
2. 처음 보는 문서 4개에서도 v2가 안정적인가 — 표본을 8문서로 늘려 가중치 재검토(v1 #7)의 재료를 만든다
3. v2 #6(식별자 인용 금지)이 지켜지는가
4. v2 #7: 채점자는 퍼센트를 쓰지 않고, `집계.py`가 판정 줄에서 계산한다
