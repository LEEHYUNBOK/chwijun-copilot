# v4 재테스트 — 설계와 사전 예측 (실행 전 고정, 결과는 `13_v4재테스트.md`)

> 2026-11-15. 이 파일은 채점자 실행 직전에 SHA-256을 `사전예측_해시_v4.txt`에 기록하고 이후 고치지 않는다.

## 목적

1. v4 #1(문서 유형별 읽는 법)이 조사 문서 e4의 불일치(C1·C3·C4)를 해소하는가
2. 유형 판정 자체가 새 불일치 지점이 되지 않는가
3. v4 #1-b(장애 C4)·#1-c(벤치마크 표본 규모)·#3(현황 수치)이 의도대로 판정을 바꾸는가
4. 처음 보는 문서 2개(조사 1·프로젝트 1)에서도 유지되는가 — 누적 채점 위키 12개

| 항목 | 내용 |
