# 완전 따라하기 — 비전공자용 처음부터 끝까지

개발을 모르는 사람(기획·디자인·마케팅·영업·그 외 전부)이 **아무것도 설치돼 있지 않은 상태에서** 공고 판정과 경력 위키까지 가는 가이드다. 화면에 뜨는 것과 입력할 것을 순서대로 적었다. 용어가 나오면 그 자리에서 풀이한다.

길은 두 개다. 어느 쪽이든 아래에서 하나만 따라가면 된다.

| | **A. 웹 챗봇 길 (5분)** | **B. Claude Code 길 (30분)** |
|---|---|---|
| 설치 | 없음 — 쓰던 ChatGPT·Gemini·Claude 그대로 | 프로그램 1개 설치 |
| 되는 것 | 공고 판정, 서류 규칙, 팔로업 판단 | 전부 + 위키·트래커 **자동 기록**, 공고 일괄 스캔 |
| 추천 대상 | 일단 써보고 싶다 | 구직 기간 내내 제대로 돌리고 싶다 |

A로 시작했다가 나중에 B로 갈아타도 된다 (프로필은 그대로 들고 간다).

---

## A. 웹 챗봇 길 — 설치 없이 5분

### A-1. 로더 복사하기

"로더"는 챗봇에게 "이 규칙대로 일해라"라고 알려주는 **문단 하나**다. 이걸 복사한다:

1. 이 링크를 연다: [chatbot/LOADER.md](../chatbot/LOADER.md)
2. 페이지 중간의 **회색 상자**(「붙여넣을 로더」 아래)에 마우스를 올리면 오른쪽 위에 **네모 두 장이 겹친 복사 아이콘**이 나타난다. 그걸 누른다 — 끝. (드래그해서 Ctrl+C / ⌘+C 해도 된다)

### A-2. 챗봇에 붙여넣기

쓰는 챗봇을 열고, 새 대화 입력창에 붙여넣고(Ctrl+V / ⌘+V) 전송한다. 이걸로 **이 대화 동안은** 동작한다.

매번 붙여넣기 싫으면 1분 더 써서 고정해 두자 (권장):

- **ChatGPT**: 왼쪽 메뉴 GPTs → Create → **Instructions** 칸에 붙여넣기 → **Web Browsing 켜기** → 저장. 이후 대화는 이 GPT를 선택해서 시작
- **Gemini**: Gems → 새 Gem → **Instructions** 칸에 붙여넣기 → 저장
- **Claude**: 프로젝트 만들기 → **프로젝트 지침** 칸에 붙여넣기 → 이후 대화는 이 프로젝트 안에서

### A-3. 온보딩 — 프로필 만들기

대화창에 이렇게만 친다:

```
온보딩
```

직군을 묻고, 경력을 한 번에 하나씩 인터뷰한다. 답하는 요령은 두 가지뿐이다:

- 아는 건 숫자까지: `가람테크 2023.09 ~ 2024.12, 정규직, 물류센터 소모품 영업`
- 모르는 건 그냥: `모름` ← 지어내는 것보다 백배 낫다. 챗봇도 지어내지 않는다

끝나면 **프로필.md**라는 글을 만들어 준다. 이게 앞으로 모든 판정의 기준이다. 통째로 복사해서:

- GPT·Gem·프로젝트를 만들었다면 → 그 **지식(Knowledge) 파일**로 저장해 둔다
- 안 만들었다면 → 메모장에 보관했다가 대화마다 맨 앞에 붙여넣는다

### A-4. 공고 판정 받기

공고 내용을 복사해서 이렇게 보낸다:

```
이 공고 넣어도 될까요?

[공고]
회사: ○○(주) / 포지션: ○○ (경력 2~5년)
필수: (공고의 자격요건 붙여넣기)
우대: (공고의 우대사항 붙여넣기)
```

적합도 점수(0~100)와 **갭**(모자란 것)을 솔직하게 알려주고, 부적합이면 넣지 말라고 한다. 마지막 줄 안내대로 **결과를 복사해 본인 메모·노션·스프레드시트에 붙여 두면** 그게 지원 기록이 된다.

### A-5. 그 다음

- 자소서: `자소서 문항 다듬어줘` + 소재(상황 → 내가 한 일 → 결과 숫자)
- 답 없는 회사: `답 없는 데 있나 봐줘` + 회사/단계/날짜 목록
- 자세한 입력 형식: [프롬프트 가이드](프롬프트-가이드.md) · 화면과 함께: [웹 챗봇판 사용설명서](사용설명서-웹.md)

## B. Claude Code 길 — 풀기능 30분

### B-0. 먼저 알아둘 세 단어

- **터미널**: 마우스 대신 글자로 명령하는 창. 까만 화면이 떠도 고장이 아니다. 이 가이드에서 터미널에 치는 건 전부 `이런 상자` 안에 있다 — 그대로 복사해 붙여넣고 Enter만 치면 된다
- **Claude Code**: 터미널에서 도는 Claude. 챗봇과 달리 **내 컴퓨터의 파일을 직접 읽고 쓸 수 있어서** 위키·지원 기록이 자동으로 쌓인다
- **플러그인**: Claude Code에 끼우는 확장 기능. 취준 코파일럿이 그 플러그인이다

### B-1. 준비물

- **Claude 유료 계정** — Pro·Max·Team·Enterprise 중 하나. 무료 claude.ai 요금제로는 Claude Code를 쓸 수 없다. API 키 발급 같은 건 필요 없다 — 구독 계정으로 로그인하면 끝
- 컴퓨터 (맥 또는 윈도우)

### B-2. Claude Code 설치

**맥**: Spotlight(⌘+Space)에 `터미널`이라고 쳐서 터미널을 열고, 아래 한 줄을 붙여넣고 Enter:

```
curl -fsSL https://claude.ai/install.sh | bash
```

**윈도우**: 시작 메뉴에 `PowerShell`이라고 쳐서 열고(관리자 권한 불필요), 아래 한 줄을 붙여넣고 Enter:

```
irm https://claude.ai/install.ps1 | iex
```

설치가 끝나면 **터미널 창을 닫고 새로 연 다음** 이렇게 쳐서 확인한다:

```
claude --version
```

버전 번호(예: 2.1.211)가 나오면 성공. `command not found`가 나오면 [공식 설치 문제 해결 페이지](https://code.claude.com/docs/en/troubleshoot-install)의 "Fix your PATH" 항목을 본다. 설치 절차가 바뀌었을 수도 있으니 안 되면 [공식 설치 문서](https://code.claude.com/docs/en/setup)가 정본이다.

**첫 실행과 로그인**: 터미널에 `claude`라고 치면 로그인 안내가 나온다. 브라우저가 열리면 Claude 계정으로 로그인 — 한 번 하면 다시 안 물어본다. 터미널 자체가 낯설면 [공식 터미널 입문 가이드](https://code.claude.com/docs/en/terminal-guide)를 먼저 봐도 된다.

### B-3. 플러그인 설치

Claude Code가 열린 상태(입력창에 `>`가 깜박인다)에서, 아래 두 줄을 한 줄씩 붙여넣고 Enter:

```
/plugin marketplace add LEEHYUNBOK/chwijun-copilot
/plugin install chwijun-copilot
```

중간에 "설치할까요?" 같은 확인이 뜨면 Enter(또는 y)로 승인하면 된다.

### B-4. 온보딩 — 경력 위키 만들기

```
/chwijun-copilot:wiki-bootstrap
```

- 직군을 묻는다 — 개발이 아니어도 된다 (기획/PM · 디자인 · 마케팅, 그 외는 직접 입력. 영업·회계·간호사 프로필로도 검증돼 있다)
- 위키를 **어느 폴더에 만들지** 묻는다 — 모르겠으면 제안해 주는 위치를 그대로 승인하면 된다
- 경력 인터뷰가 이어진다. 요령은 A-3과 같다: 아는 건 숫자까지, 모르는 건 `모름`

끝나면 폴더에 파일이 생긴다. 탐색기(파인더)에서 열어 보면 그냥 글 파일이다:

- `프로필.md` — 판정 기준 (⭐ 한 번 직접 읽고, 사실과 다른 곳을 고쳐 달라고 말할 것)
- `지원현황.md` — 지원 기록이 자동으로 쌓이는 곳
- `문서/` — 대표 경험의 상세 기록

> `.md` 파일은 메모장으로도 열리는 일반 텍스트다. 더블클릭해서 읽으면 된다.

### B-5. 일상 사용 — 전부 말로 하면 된다

명령어를 외울 필요 없다. 터미널이라고 해서 특별한 문법이 있는 게 아니다:

```
이 공고 봐줘 https://...
```
```
새 공고 스캔해줘
```
```
자소서 문항 좀 다듬어줘
```
```
답 없는 데 있나 봐줘
```

공고 판정 결과는 `지원현황.md`에 **자동으로 기록**된다 — A길과 달리 복사해 둘 필요가 없다.

관심 회사를 등록해 두면 "새 공고 스캔해줘" 한마디로 전부 훑는다. 등록도 말로 하면 된다:

```
watchlist에 토스랑 당근 추가해줘
```

### B-6. 일하면서 위키 키우기

위키는 온보딩 때 한 번 만들고 끝이 아니다. **일이 끝날 때마다** 이렇게 말해서 쌓는다:

```
이거 위키에 기록해줘. 이번 분기 재계약 지켰어.
단가 인하 압박이 있었는데 월 발주 주기를 제안해서 12개월 연장했고,
번들 단가는 -4%로 협상했어. 최종 승인은 팀장님.
```

기준 없는 숫자("120% 달성"), 남의 몫 섞기("팀 리딩")는 기록 단계에서 걸러서 되묻는다 — 그 교정이 쌓인 위키가 곧 **면접에서 무너지지 않는 서류의 재료**다. 문서 하나가 만들어지는 과정과 완성 모습은 [내 위키 만들기](위키-만들기.md), 위키로 지원을 돌리는 운용법은 [워크플로우 가이드](워크플로우-가이드.md)에 있다.

## 막혔을 때

**터미널에 붙여넣기가 안 된다**
맥은 ⌘+V. 윈도우 터미널은 Ctrl+V가 안 되면 마우스 오른쪽 클릭이 붙여넣기다.

**공고 URL을 줬더니 404라고 한다**
공고가 내려갔거나 주소가 깨진 것. 공고 페이지의 글을 통째로 복사해 붙여넣으면 똑같이 판정된다.

**점수가 생각보다 짜다**
정상이다. 프로필로 입증 안 되는 요구사항은 전부 갭으로 센다. 점수를 올리는 유일한 방법은 프로필에 실제 경험을 채우는 것이다.

**뭘 잘못 눌러서 이상해졌다**
Claude Code는 `Esc`로 진행 중인 걸 멈출 수 있고, 터미널 창을 닫고 다시 열어 `claude`를 쳐도 된다. 위키 파일은 내 컴퓨터에 그대로 있다.
