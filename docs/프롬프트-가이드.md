## 1. 공고 판정

URL이 살아 있으면 이게 전부다:

```
이 공고 봐줘 https://...
```

URL이 404거나, 사람인·원티드처럼 다른 본문이 열릴 수 있는 곳이면 **본문을 직접 붙여넣는 게 가장 확실하다**. 이 형식이면 한 번에 끝난다:

```
이 공고 넣어도 돼요? 본문 붙여넣을게요.
회사: 베리온솔루션(주) / 포지션: B2B 영업 담당 (산업 장비 소모품·렌탈)
링크: https://example.com/jobs/verion-b2b-sales
요구: 경력 3년 이상(3~7년), 신규 개척~클로징 전 과정 경험 필수, 연간 목표 달성 경험 필수
우대: 공공·입찰 경험, CRM 활용, 영어 가능, 정기 거래처 관리 경험
업무: 기존 거래처 관리 + 신규 개척, 월 목표 관리
```

- 핵심은 **회사 · 포지션 · 요구(필수) · 우대**다. 이 넷이 있어야 갭 대조가 된다
- 근무지 · 마감일 · 전형 절차도 있으면 같이 — 없으면 "미기재"로 기록된다
- 공고 원문을 통째로 복사해 붙여도 된다. 위 형식은 요약해서 줄 때의 최소 골격이다

판정이 나온 뒤 더 묻고 싶으면 그냥 이어서 묻는다:

```
갭 중에 제일 큰 게 뭔가요? 보완 방법도 알려주세요.
```

## 2. 프로필 + 공고 한 번에 (웹 챗봇판)

웹 챗봇은 파일 시스템이 없으므로, 프로필을 프로젝트 지식에 안 넣어둔 대화라면 둘을 한 메시지에 붙인다:

```
프로필이랑 공고 붙여넣을게요. 이 공고 넣어도 될까요?

[프로필.md]
- 직군: 퍼포먼스 마케터, 경력 2년 3개월 (커머스 스타트업 1곳)
- 대표 실적: 메타·구글 광고 월 예산 4,000만 원 운영, ROAS 320% → 410% (2025 상반기)
- 공백: GA4 세팅 직접 경험 없음, 브랜드 마케팅 경험 없음, 팀 관리 경험 없음

[공고]
회사: 뮤즈커머스(주) / 포지션: 퍼포먼스 마케터 (경력 2~5년)
근무지: 서울 성수 / 마감: 2026-10-26
필수: 매체 광고 운영 2년 이상, ROAS·CAC 등 지표 기반 예산 운영 경험
우대: GA4·GTM 직접 세팅, 뷰티 커머스 도메인, 월 예산 1억 이상 운영
```

- 프로필에서 빠지면 안 되는 건 **「공백」**이다. 공백 없는 프로필은 판정이 후해지는 게 아니라 판정이 작동하지 않는다
- 실적 숫자는 **before→after**로 (예: `ROAS 320% → 410%`). "30% 개선" 같은 상대 수치 하나만 주면 교정 질문이 돌아온다

## 3. 온보딩 인터뷰에 답하는 형식

시작은 한 마디다 (CLI판은 `/chwijun-copilot:wiki-bootstrap`도 된다):

```
온보딩 시작
```

경력을 물으면 회사마다 네 가지로 답한다:

```
다온오피스 2022.01 ~ 2023.06, 정규직, 사무용품 B2B 영업 (거래처 관리 + 신규 개척)
가람테크 2023.09 ~ 2024.12, 정규직, 물류센터 소모품 영업
```

- 기간은 **년.월 단위**로. 인터뷰가 합산 개월수를 직접 검산한다
- 실적을 말할 때는 숫자의 기준을 같이: `분기 개인 목표 2,500만 원 대비 120%` (기준 없는 "120% 달성"은 되묻는다)
- 팀 성과면 팀 성과라고: `팀 5명 합계 연 수주 10억, 제 기여는 1.4억쯤`

## 5. 이력서·자소서 재료 주기

요청은 자연어로 하고, 소재는 **상황 → 내가 한 일 → 결과 숫자** 세 토막으로 준다:

```
자소서 문항 좀 다듬어줘. 소재는 이거예요.
- 상황: 분기마다 단가 인하 압박, 경쟁사 견적으로 이탈 위기
- 내가 한 일: 월 단위 발주 주기 제안, 번들 단가 -4% 직접 협상 (최종 승인은 팀장)
- 결과: 12개월 재계약 유지
```

- 남이 한 일(선임 담당, 디자이너 제작 등)은 그렇게 표시한다 — 내 것처럼 쓰면 교정된다
- 세 토막 중 비는 게 있으면 비워서 낸다. 지어서 채우는 것보다 낫다 (하나씩 물어서 채워 준다)

## 6. 기업분석 자소서 — 회사를 파고 쓰는 문항

지원동기·기업분석형 문항은 조사가 절반이다. 분석부터 작성까지 한 번에 시키는 서식:

```
○○(주) 기업분석부터 해서 자소서 써줘.

[분석]
1. 경쟁사 · 고객 · 상품 분석
2. 이 회사가 지금 올린 채용공고 전부 찾아서 JD 전수조사 — 직군 막론하고 반복되는 요구·키워드 추출
3. 핵심가치 · 인재상 · 컬처핏 정리

[자소서 문항]
(문항 원문 그대로, 글자수 제한 포함)

[내 소재]
(상황 → 내가 한 일 → 결과 숫자 — 5번 형식)
```

- **JD 전수조사가 핵심이다.** 지원하는 공고 하나의 JD는 인사팀 표현이고, 전 직군 공고에서 반복되는 키워드가 회사가 실제로 굴리는 우선순위다
- 분석 결과는 문장에 베끼는 게 아니라 **소재 선택과 ②왜 이 회사인가의 근거**로 쓰인다 — 인재상 단어를 그대로 박으면 교정된다
- `[내 소재]`가 없으면 분석 보고까지만 나온다. 프로필·소재에 없는 경험으로 자소서를 지어 주지는 않는다
- 웹 챗봇판은 검색(Web Browsing)이 켜져 있어야 전수조사가 된다. 꺼져 있으면 그 회사 공고 2~3개를 직접 복사해 붙인다

## 7. 팔로업 점검

트래커가 있는 CLI판은 한 마디:

```
답 없는 데 있나 봐줘
```

웹 챗봇판은 지원 상태를 붙여준다:

```
답 없는 데 있나 봐줘. 지금 상태는 이래요.
- 당근 / 백엔드 / 지원완료 09-10
- 나다커머스 / 서버 엔지니어 / 1차 면접 09-22, 이후 연락 없음
- 가나페이 / 백엔드 / 지원완료 09-29
```

회사 · 직무 · 단계 · 날짜 네 가지면 판정(기다려라/문의해라/정리하자)이 나온다.

## 8. 탈락 패턴 분석

```
계속 떨어지는데 왜지
```

기록이 없으면 분석 대신 "채우는 법"이 돌아온다. 기억나는 만큼 이 형식으로 주면 소급 등록된다:

```
떨어진 곳들 불러줄게요.
- A사 / 백엔드 3년차 공고 / 서류 탈락 / 맞춤 지원
- B사 / 백엔드 5년차 이상 / 서류 탈락 / 일괄 지원
```

회사 · 공고 연차 · 탈락 단계 · 맞춤/일괄 — 이 네 가지가 패턴 소거의 재료다.

## 9. 모르면 "모름" — 그것도 형식이다

인터뷰나 판정 중에 모르는 숫자·사실을 물어오면, 지어내지 말고 이렇게 답한다:

```
모름
```

```
그건 없어요
```

그러면 그 항목은 `{{추가 확인}}`으로 남고, 인과를 주장하지 않는 안전한 문장으로 쓰인다. 애매하게 둘러대는 것보다 "모름"이 서류 품질에 낫다 — 이 동작은 QA 시뮬레이션에서 반복 검증된 것이다.
