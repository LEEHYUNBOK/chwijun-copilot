# 사용설명서

쓰는 환경에 따라 두 가지 방식이 있다. 하나를 골라 해당 매뉴얼로 가면 된다.

| | **CLI판** — Claude Code 플러그인 | **웹 챗봇판** — 라이트 |
|---|---|---|
| 어디서 | 터미널 Claude Code | ChatGPT · Gemini · Claude.ai |
| 설치 | `/plugin` 명령 2줄 + 온보딩 1회 | 로더 문단 1개 붙여넣기 (프로젝트·GPT·Gem 권장) |
| 되는 것 | 전 기능 — 경력 위키·트래커 자동 기록, 관심회사 일괄 스캔, ATS 수집 | 판정·서류 규칙 전부 (기록은 복사해서 직접) |
| 매뉴얼 | **[📖 CLI판 사용설명서](사용설명서-cli.md)** | **[📖 웹 챗봇판 사용설명서](사용설명서-웹.md)** |

- 풀기능이 필요하거나 Claude Code를 이미 쓴다 → **CLI판**
- Claude Code가 없다, 챗봇으로 가볍게 쓰고 싶다 → **웹 챗봇판**

두 판 모두 계약은 같다: **창작 금지**(프로필·공고에 없는 건 지어내지 않는다) + **아부 금지**(갭을 먼저 말하고, 부적합이면 지원하지 말라고 한다). 매뉴얼의 스크린샷은 전부 실제 실행 출력이다.

무엇을 어떤 형식으로 입력하면 되는지는 **[📋 프롬프트 가이드](프롬프트-가이드.md)** — 공고·프로필·소재·지원 상태를 붙여넣는 서식 모음 (두 판 공통).

도구를 익힌 다음은 **[🔁 실전 워크플로우 가이드](워크플로우-가이드.md)** — 일하면서 소재를 기록하고, 경력 위키를 키우고, 그 위키로 지원을 돌리는 운용 방법 (두 판 공통).
