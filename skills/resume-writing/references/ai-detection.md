## 프레이밍부터

요즘 인사팀은 이력서를 거를 때 AI 사용도를 본다. AI를 쓴 게 보여도 통과하는 경우가 있는데, 그건 "AI로 쓴 것 같은 정도"가 기준치보다 낮았기 때문이다.

그런데 목표를 "검사기 회피"로 잡으면 작업 방향이 이상해진다. 문장만 흐트러뜨리고 알맹이는 그대로인 글이 나온다. 그건 검사기도 잡고 면접관은 더 빨리 잡는다.

**실제로 통하는 순서는 반대다.** 본인이 진짜 한 일을, 본인 어휘로, 숫자와 함께 쓰면 검사기는 그냥 통과한다. AI가 못 쓰는 것은 문체가 아니라 **당신만 아는 구체적 사실**이다. 어떤 라이브러리를 왜 버렸는지, 어떤 수치가 얼마에서 얼마로 갔는지, 사수 없이 기술을 고를 때 뭐가 부담이었는지 — 여기서 승부가 난다.

그래서 아래 세 가지는 이 순서로 쓴다.

1. 프롬프트 설계 — AI에게 무엇을 줄지
2. 출처 신뢰성 — 사실 근거를 어디서 가져올지
3. 인간화 — 마지막에 문체를 다듬을지

그리고 **마지막은 반드시 직접 손으로 고치고, 외운다.** 면접에서 자기 이력서를 설명 못 하면 앞의 전부가 무의미하다.

## 1. 프롬프트 설계

### 먼저 주입할 것

- 채용공고 원문
- 회사의 인재상
- 기존 이력서 / 실제 경험 재료

이 셋 없이 요청하면 어디에나 붙는 일반론이 나온다.

### 요청은 제약과 함께

```
내 이력서와 공고를 참고해 300자 이하의 간단한 자기소개를 작성해줘.
[X] 업계 [Y] 직무의 전문성을 강조한 3문장 길이의 요약을 만들어줘.
나의 주요 성과와 경력을 한눈에 보여주는 임팩트 있는 소개글을 써줘.
```

글자수, 문장 수, 강조점을 못 박는다. 제약이 없으면 분량을 채우려고 상투어가 들어간다.

### 항상 덧붙일 것

> 두루뭉실한 AI스러운 언어를 쓰지 말고, 계속 같은 방식으로 문장을 구성하지 마.

## 2. 출처 신뢰성

GPT나 Gemini는 레딧 같은 소셜미디어 글을 근거로 끌어오는 일이 잦다. 출처가 중요한 내용(업계 동향, 기술 트렌드, 회사·산업 정보)을 쓸 때는 출처가 명시되는 도구를 쓴다.

- **Liner AI** — 기간 필터를 걸 수 있고, 결과를 클릭하면 우측에 출처가 전부 뜬다. <https://hey.liner.com/vlc7pf>

핵심은 검증만이 아니다. **출처를 직접 읽어두면 면접에서 할 말이 하나씩 늘어난다.** 이력서에 쓴 한 줄의 배경을 물었을 때 근거를 대며 답할 수 있는지가 갈린다. 출처 확인은 사실 확인이 아니라 면접 준비다.

## 3. 인간화

### 원문 프롬프트 (그대로 사용)

> 이 글을 작성할 때 AI 특유의 딱딱하고 정형화된 문체는 완전히 버려줘. 문장의 길이를 아주 짧은 것과 긴 것이 교차되도록 섞어서 리듬감을 만들고, '또한', '결론적으로', '결과적으로' 같은 상투적인 접속사는 절대 쓰지 마. 대신 구어체적인 표현이나 실무에서만 쓰는 생생한 단어를 섞어서 사람이 직접 고민하며 쓴 것 같은 느낌을 줘. 특히 문장 구조가 너무 완벽하게 반복되지 않도록 의도적으로 어순을 바꾸거나 강조점을 뒤섞어서, AI 감지기가 분석할 수 없는 불규칙한 패턴을 만들어줘

이미 인간화가 적용된 GPTs를 쓰는 방법도 있다.

### 손으로 고칠 때 보는 것

| 신호 | 조치 |
|---|---|
| 문장 길이가 다 비슷하다 | 하나를 반토막 내고, 하나를 붙여서 길게 |
| "~하여 ~했습니다"가 3연속 | 하나는 어순을 뒤집는다 |
| "~하고, ~하며," 나열 체인 | 문장을 끊어 두세 문장으로. 연결어미 뒤 쉼표는 한국어 AI 최강 지문(인간 4% vs AI 20%, writing-voice 규칙과 동일) |
| 접속사로 시작하는 문장 | 지운다. 대부분 지워도 말이 된다 |
| 교과서 용어만 있다 | 실무에서 쓰는 말로 바꾼다 (예: "장애 대응" → "새벽에 알람 받고 롤백") |
| 모든 불릿이 같은 길이 | 일부러 흐트러뜨린다 |
| 완벽한 대구 구조 | 한쪽을 깬다 |

### 반대로, 손대지 말 것

- 숫자와 고유명사 — 리듬 때문에 정확도를 버리면 안 된다
- 기술 용어의 정식 명칭
- 종결어미 통일 — 문체는 통일, **문장 구조는 비통일**

## 4. 권장 파이프라인

```
채용공고·인재상·내 경험 정리
   ↓
출처가 필요한 부분은 Liner로 근거 확보 (+ 출처 원문 읽어두기)
   ↓
인간화 프롬프트를 붙여 초안 생성
   ↓
직접 읽으며 내 입맛대로 수정        ← 생략 불가
   ↓
rule.md 8장 체크리스트로 검수
   ↓
내용을 외운다 (면접 대비)           ← 생략 불가
```

마지막 두 단계를 건너뛰면 앞의 노력이 전부 날아간다.
