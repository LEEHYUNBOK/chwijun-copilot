# HTML 이력서·경력기술서 + PDF 추출

초안(텍스트)이 확정된 다음 단계다. 초안 없이 바로 HTML부터 채우지 않는다.

## 절차

1. 템플릿 복사: `<플러그인 루트>/templates/이력서.html` 또는 `경력기술서.html`을 `<wiki_path>/서류/`로 복사한다 (파일명: `이력서_<이름>.html`).
2. 채움: `{{...}}` 플레이스홀더를 전부 치환한다. 재료는 확정 초안과 `<wiki_path>/프로필.md`.
   - 프로필의 **「표기 규칙」을 그대로 적용**한다 — 금지 표현이 서류에 들어오면 안 된다.
   - 확인 안 된 값은 지어내지 말고 `[추가 확인 필요: 무엇]`으로 남긴다.
   - 안 쓰는 섹션(자격증 없음 등)은 플레이스홀더를 남기지 말고 **섹션째 삭제**한다.
3. 추출: `bash "<스킬 베이스 디렉터리>/../../scripts/export_pdf.sh" <html>` — 페이지 수가 출력된다.
   - exit 2 = 브라우저 없음: HTML만 전달하고 "브라우저 인쇄 → PDF 저장(머리글·바닥글 끄기)"을 안내한다.
   - "플레이스홀더 잔존" 경고가 나오면 미완성이다 — 채우고 재추출.
4. 검증 후 보고: 페이지 수(이력서 2p·경력기술서 2p 이내), 잔존 경고 0건을 확인하고 파일 경로와 함께 보고한다.

## 레이아웃 주의 (템플릿을 고칠 때)

- **사이드바(float)는 1페이지에서만 유효하다.** float은 line box만 밀기 때문에 표·flex·배경박스가 사이드바를 뚫는다 — 그런 요소는 사이드바 옆에 두지 말고, 2페이지 이후는 `--ind` 들여쓰기로 정렬한다.
- 여백은 `@page`에 고정돼 있다 — 브라우저 인쇄 설정으로 바꾸지 않는다.
- 항목이 페이지 경계에서 잘리면 `.item`(break-inside: avoid) 단위를 유지한 채 순서만 조정한다.
