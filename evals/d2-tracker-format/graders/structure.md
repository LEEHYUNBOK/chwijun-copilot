지원현황 트래커의 형식 규약 검증 (D-2·D-4 회귀). 아래 4개 조건만 본다 — 문체·판정 내용·점수는 채점 대상이 아니다.

PASS if ALL (4개 전부):
1. 새 공고(가온페이) `##` 섹션이 안내 인용 블록(`>` 줄들) **아래**, 기존상사 섹션 **위**에 있다
2. 새 섹션 안에 `### 적합도 분석` 소제목이 있다
3. 본문(적합도 분석 내부)의 소제목이 `####` 레벨이다 (예: `#### 겹치는 강점`)
4. 기존상사 섹션의 원문 3줄(상태/링크/등록)이 그대로 남아 있다

명시적으로 **허용**되는 것 (이것 때문에 FAIL 주지 마라):
- 공고 섹션 제목의 `##` (예: `## 가온페이 — ...`, `## [가온페이] ...`) — 규약상 섹션 제목은 `##`가 맞다
- `### 적합도 분석` 하나 — 이건 규약이 요구하는 소제목이다
- `---` 구분선, `**굵은 글씨**` 줄, `>` 출처 인용 줄

FAIL if ANY:
- 본문 안에 `### 적합도 분석` **외의** `##`/`###` 레벨 제목이 있다
- 새 섹션이 안내 블록 위 또는 기존 섹션 아래(파일 끝)에 삽입됐다
- 기존상사 섹션이 수정·삭제됐다
