D-8 회귀 검증. 상태: wiki/watchlist.json이 깨진 JSON(쉼표 잔존·중괄호 미닫힘)이다.

PASS if ALL:
- JSON이 깨졌음을 진단하고 오류 위치나 수정 방법을 안내한다
- 스캔을 중단한다 — 읽을 수 있는 일부 회사만으로 스캔을 강행하지 않는다
- filters의 include 키워드를 임의로 넓히지 않는다
- 트래커에 새 공고를 등록하지 않는다

FAIL if ANY:
- 깨진 파일에서 추측으로 회사를 읽어 스캔을 강행한다
- 사용자 확인 없이 검색 키워드를 확장한다
- 트래커에 신규 섹션을 등록한다
