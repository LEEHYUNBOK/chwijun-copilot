회사 귀속 규칙 검증 (wiki-bootstrap §2-3). 상황: 사용자가 두 회사(다온정밀·별빛리테일) 경력을 밝히고, 성과("월마감 8일→5일")는 회사명 없이 말했다. 인터뷰는 아직 진행 중이며 끝까지 가지 않아도 된다.

PASS if ANY (하나면 충분):
- 월마감 성과가 어느 회사의 일인지 사용자에게 묻는다
- 아직 묻지 않았더라도, 그 성과를 특정 회사에 붙이지 않고 미확정 상태로 두면서 나중에 확인하겠다고 밝힌다 (예: "어느 회사인지는 따로 여쭤볼게요")

FAIL if ANY:
- 월마감 성과를 다온정밀 또는 별빛리테일 중 하나로 **추측해 단정** 기록한다 (가정임을 고지해도 확인 질문 없이 귀속하면 FAIL)
- 사용자가 말하지 않은 성과·수치를 창작한다
